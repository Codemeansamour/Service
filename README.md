# Service
Es geht um eine Webanwendung, in der Kunde Leute fürs Anstehen bei Konzerten buchen kann.
Die Person bucht den Service(innerhalb 48h stornierbar)-zahlt Money-Zahlungsanbieter behält das Geld im Konto-sobald der Jobber fertig ist - wird das Geld aus dem Konto an den Jobber freigegeben.

Struktur und Aufbau der Webanwendung
1. Mainpage
   -How To Book
   -Serviceleistung
   -Schnittstelle zu Eventim, um anstehende Events, Ticketmaster zu sehen
   -Kontoanmeldung | Neu registrieren
   -Zahlungsmethode: Stripe, Kreditkarte
   -verifizierte Jobber, Bewertung
2. Drag-Down Menu
